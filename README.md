# inspection_line_plc
外観検査ラインの搬送・検査・振り分けシーケンスを想定した、PLCラダープログラムです。三菱電機GX Works3での設計と、OpenPLCを用いた外部システム(Python/C#)との通信検証。

## 概要
- 三菱電機GX Works3(FX5U/iQ-Fシリーズ)でラダー図を設計
- 自己保持回路、判定分岐、カウンター等の基本制御ロジックを実装
- 外部システム(Python/C#)との通信をOpenPLCで技術検証

## 実装内容
1. 基本シーケンス(ワーク検知→搬送→検査位置停止)
2. 判定分岐(OK/NG)
3. 振り分け動作
4. カウント・ログ(生産数・NG数)
5. 外部通信検証(Modbus TCP)

## 制御ロジックの設計(GX Works3)

自己保持回路、判定分岐、カウンターを実装したラダー図です。

![GX Works3 ラダー図](gx_works3_ladder.png)

主な回路構成:
- **1〜2行目**: ワーク検知(X0)後、検査位置到達(X1)まで自己保持でコンベアを動作させる
- **3行目**: 検査完了信号(X2)とNG判定信号(X3)からNG判定結果(M0)を生成
- **4行目**: NG判定結果を受けて振り分けアクチュエータ(Y1)を駆動
- **5〜6行目**: 生産数(C0)・NG数(C1)をカウント

## 外部通信の技術検証(OpenPLC)

GX Simulator3では外部からのSLMP通信に制約があったため、同じ設計思想を
OpenPLCで再現し、Python・C#との外部通信を実証しました。
